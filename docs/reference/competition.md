# การแข่งขัน Autonomous Drone Simulation (สรุป)

> สรุปจาก `competition-source.md` (สไลด์ที่แปลงจาก PDF ข้อความเพี้ยนบางส่วน) · เว็บโครงการ: https://nt-drone.ntplc.co.th · สรุปเมื่อ 2026-10-24
> ส่วนที่อ่านไม่ออกมีระบุท้ายไฟล์ · ห้ามถือเป็นกติกาทางการ ให้ตรวจกับเอกสารต้นฉบับ

## ภาพรวม

- ผู้จัด: NT (จัดเตรียมแพลตฟอร์มและเครื่องมือ กำกับการแข่งขัน) · TESA (สนับสนุนด้านเทคนิค อบรม พัฒนาโจทย์) · จปร. (ร่วมจัด เป็นประธานกรรมการรอบชิง)
- เป้าหมาย: พัฒนาบุคลากรด้านโดรนอัตโนมัติและ AI ของไทย ส่งเสริม NT Flight Control และ NT Digital Twin
- ทุกทีมใช้แพลตฟอร์ม อุปกรณ์ HIL โจทย์ และเงื่อนไขชุดเดียวกัน ประเมินด้วยระบบอัตโนมัติและกรรมการตรวจสอบ

## รูปแบบการแข่ง

- **Object detection:** ดาวน์โหลดวิดีโอการบิน simulation (MP4) ที่ผู้จัดเตรียมไว้ แล้วใช้ AI computer vision ตรวจจับวัตถุ
- **Autonomous:** ส่ง log file และควบคุมผ่าน virtual remote control พร้อม flight telemetry (ข้อความต้นฉบับเพี้ยน)

## ผู้สมัคร

- นิสิต/นักศึกษาไทย ทีมละ 1–3 คน มีอาจารย์ที่ปรึกษาอย่างน้อย 1 คน
- รับไม่เกิน 50 ทีม แต่ละคณะส่งได้ไม่เกิน 2 ทีม · สมัครฟรีออนไลน์ แนบเอกสารภายในเวลาที่กำหนด
- รอบคัดเลือก: ไม่เกิน 50 ทีม โจทย์เดียวกัน · รอบชิง: 8 ทีม ภารกิจซับซ้อนขึ้น มีกรรมการพิจารณา

## Flow ของระบบ (ตารางสถาปัตยกรรม 8 ขั้น)

ตารางเพี้ยนมาก อ่านได้เท่านี้ (ลำดับ ไม่ใช่รายละเอียดพอร์ต/โปรโตคอล):

1. ทีม push Docker image ขึ้น Docker Hub (HTTPS)
2. ทีมต่อ VPN (WireGuard) กับ VPN server
3. VPN server ↔ ฐานข้อมูลภายใน (ตารางเวลา VPN)
4. VPN schedule ↔ API/Dashboard/Portal ผ่านฐานข้อมูลร่วม
5. ทีมเข้า Portal/Dashboard ผ่าน VPN
6. Dashboard/Portal เรียก Docker registry API ดึง image จาก Docker Hub เมื่อกด "Start"
7. Dashboard/Portal → System Control ด้วย HTTP POST (Mission Scenario)
8. System Control เรียกสคริปต์ จุดชนวน simulation container แบบ software-in-the-loop (SIL)

ตารางระบุผู้รับผิดชอบเป็น "WIN" และ "TONG" ในหลายขั้น (ขั้น 7 ระบุ TONG)

**ตำแหน่งของ flight-service:** น่าจะตรงขั้น 7–8 (รับคำสั่งแล้ว pull/load image และบินใน sim) ส่วนขั้น 1–6 เป็นระบบฝั่งผู้จัด/พี่ต้น · ยังไม่ยืนยันกับพี่ต้น

## ที่ไฟล์ต้นฉบับอ่านไม่ออก / ไม่บอก

- พอร์ต โปรโตคอล และรูปแบบ body ของ POST (Mission Scenario) ในตาราง flow
- ชื่อหัวข้อบางส่วนและข้อความภาษาไทยที่ฟอนต์เพี้ยน (เช่น หัวข้อรูปแบบ Autonomous, งบ NT)
- วันที่ Tutorial กับ Boot camp แยกกันอย่างไร
- นิยามคะแนนภารกิจ/เส้นทาง/เวลา/เสถียรภาพ/รับมือเหตุการณ์/ความปลอดภัย
